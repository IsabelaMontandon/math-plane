# Math Plane

Math Plane é um jogo educativo desenvolvido como projeto da disciplina de Desenvolvimento de Games.

A proposta do jogo é praticar as quatro operações matemáticas de forma visual e interativa. O jogador controla um avião e precisa escolher o caminho correto entre diferentes balões para alcançar a meta apresentada em cada desafio.

O jogo será desenvolvido utilizando **Godot Engine**.

## Sobre o jogo

O Math Plane é dividido em quatro ilhas, cada uma relacionada a uma estação do ano e a uma operação matemática:

- Verão — Soma
- Outono — Multiplicação
- Inverno — Subtração
- Primavera — Divisão

Cada ilha possui três níveis de dificuldade:

- **Explorador** — balões parados, permitindo que o jogador escolha o caminho com calma.
- **Piloto** — balões em movimento com velocidade moderada.
- **Comandante** — balões em movimento mais rápido, aumentando o nível de desafio.

Durante as fases, o jogador controla o avião entre quatro linhas de balões. Alguns balões possuem operações matemáticas e outros funcionam como caminhos neutros.

O objetivo é realizar as operações corretas até alcançar a meta apresentada na tela.

Além das quatro ilhas principais, o jogo também contará com um **modo ranqueado**, no qual as quatro operações matemáticas serão misturadas. O jogador terá **1 minuto e 30 segundos** para resolver o maior número possível de contas e sua pontuação será registrada em um ranking.
